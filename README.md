# AI Essential Plus 교육 노트

AI Essential Plus 교육 중 질문하고 정리한 내용을 Markdown으로 관리하고, MkDocs Material로 GitHub Pages에 배포하기 위한 저장소입니다.

## 노트 구성

- 키워드 모음
- 이론
- 실습
- 노트
- 응용
- 시험

## 로컬 실행

```bash
python -m pip install -r requirements.txt
mkdocs serve
```

## GitHub Pages

`main` 브랜치에 push하면 GitHub Actions가 MkDocs 사이트를 빌드하고 Pages에 배포하도록 구성합니다.
