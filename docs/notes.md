# 노트

## 파라미터 이해 기준점

> **모델이 학습하면서 조정해 내부에 저장한 수많은 숫자**

Fine-tuning은 이 숫자들을 추가 학습으로 바꾸는 것이다.

## Context Window 주의

`1M context`라고 해서 1M 전체를 똑같이 잘 활용하는 것은 아니다.

따라서 실제 시스템에서는:
- 필요한 정보 선별
- 긴 자료 요약
- RAG로 관련 부분 검색
- Tool 결과 압축
- 오래된 상태 정리

등이 중요하다.

## RAG에서 명확해진 점

RAG 구축 시 생성 LLM(GPT, Claude 등)을 의식하지 않았더라도 **Embedding Model은 반드시 존재**한다.

Vector DB는 임베딩 모델이 만든 벡터 공간에 의존한다.
