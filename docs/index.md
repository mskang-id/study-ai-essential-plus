# AI Essential Plus 교육 노트

AI/LLM 학습 과정에서 **직접 질문하고 이해한 개념을 중심으로** 정리하는 공개 학습 노트입니다.

## 구성

1. **키워드 모음** — 핵심 용어를 한눈에
2. **이론** — 개념 설명과 개념 간 관계
3. **실습** — 코드, 도구, 프레임워크 실습
4. **노트** — 헷갈린 부분과 추가 메모
5. **응용** — 일반화한 현업 적용 아이디어
6. **시험** — 객관식 문제의 핵심 개념과 해설

## 공개 원칙

이 사이트에는 개인정보나 특정 회사의 내부 정보가 들어가지 않도록 관리합니다. 실제 업무 사례는 일반적인 예제로 추상화하고, 교육 자료나 시험 문제 원문을 그대로 공개하지 않고 핵심 개념과 해설 중심으로 정리합니다.
