# 모델과 파라미터

## Parameter

**파라미터는 모델이 학습하면서 조정하여 내부에 저장해 둔 숫자들**이다.

가장 단순한 선형회귀:

```text
y = wx + b
```

여기서 `w`, `b`가 파라미터다.

신경망에서는 이런 weight와 bias가 매우 많이 존재하며, 학습은 이 숫자들을 조정하는 과정이라고 볼 수 있다.

### 사람 뇌 비유
- 파라미터 수와 뉴런 수는 같은 개념이 아니다.
- 파라미터는 뉴런보다는 **시냅스 연결 강도**에 더 가까운 비유다.

## Model Size

LLM에서 `7B`, `30B`, `70B`처럼 말할 때는 흔히 파라미터 수를 뜻한다.

- `30B` = 약 300억 개 파라미터

단, 문맥에 따라 파일 크기나 실제 RAM/VRAM 사용량을 모델 사이즈라고 부르기도 한다.

## Dataset Size

모델 학습에 사용된 데이터의 양이다. LLM에서는 주로 토큰 수로 표현한다.

- 예: `2T tokens` = 약 2조 토큰

### 관계

- **Dataset** = 학습에 보여준 데이터
- **Parameter** = 학습 결과 모델 안에 남은 숫자
