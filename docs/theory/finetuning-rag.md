# Fine-tuning과 RAG

## Fine-tuning

기존 모델을 추가 학습해 **모델 내부 파라미터를 바꾸는 것**이다.

즉 모델의 행동 패턴이나 반응 성향 자체를 조정한다.

## RAG

모델의 파라미터는 그대로 두고, 질문이 들어왔을 때 외부 문서에서 필요한 내용을 찾아 **컨텍스트에 넣어주는 방식**이다.

> Fine-tuning = 공부해서 머리가 바뀜  
> RAG = 필요할 때 참고자료를 찾아 펼쳐봄

## Embedding Model과 LLM

### Embedding Model

텍스트를 숫자 벡터로 바꿔 검색 가능한 형태로 만든다.

```text
문서 → Embedding Model → Vector DB
```

질문도 **같은 임베딩 모델**로 벡터화한다.

```text
질문 → 같은 Embedding Model → 유사 문서 검색
```

### LLM

검색된 문서와 질문을 읽고 최종 답변을 생성한다.

```text
질문 + 검색된 문서 → LLM → 답변
```

### 핵심 원칙

> **RAG의 벡터 인덱스는 생성 LLM에는 비교적 독립적이지만 Embedding Model에는 의존적이다.**

임베딩 모델을 바꾸면 기존 문서를 새 모델로 전체 재임베딩해 새 인덱스를 구축해야 한다.
